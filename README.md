# Team 09 — Engineering Design Worksheet

The engineering report for the **semi-automatic mechanical clock** is maintained in this repository's Wiki.

**[Open the Engineering Design Worksheet Wiki](https://github.com/R-div-Engg-Exploration-2026-27-Odd/Repo-9/wiki)**

The Wiki follows the requested engineering design process: team information, pertinent information gathering, problem definition, concept generation, concept evaluation, and product architecture.

The image files in this repository are original figures extracted from the [Team 09 source workbook](https://docs.google.com/spreadsheets/d/1oU057XgOz6YKb2Pazxcvv9_z2NFfVQNLEpiC7mCxE-M/edit). They support the Wiki's function tree, morphological chart, concept sketches, and function clustering. Captions in the Wiki identify the source and any uncertainty in the figures' relationship to the design tables.

Worksheet snapshot: 7 October 2026. Future changes to the Google Sheet are not synchronized automatically.
